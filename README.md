# lingvoigry
**Участники:** Никитин Михаил, Кукшинова Дарья, Сушко Полина, Усенко Анастасия

Проект представляет собой телеграм-бота с четырьмя лингвистическими мини-играми. Бота можно добавлять в чаты или играть в одиночку.
Поддерживаемые игры: **Лингвиселица** (классическая виселица, в которой загадываются лингвистические термины и фразеологизмы), **ХОМО** (игра, в которой участникам необходимо быстрее остальных придумать русскую словоформу с заданным буквосочетанием), **RuGramle** (по спектрограмме нужно отгадать русское существительное из 6 звуков за 6 попыток, отмечаются угаданные буквы как в Wordle), **Угадай язык** (по тексту надо понять, на каком языке он написан; есть возможность выбрать один из трех уровней сложности, система подсказок).

**Структура репозитория:** в корневой папке лежат все основные необходимые файлы (бот, модули конвертации слово > транскрипция и слово > спектрограмма, списки слов для Виселицы и ХОМО), в папке *угадай язык* содержатся все тексты (и картинки), необходимые для игры, *webparsers* содержит коды, использованные для парсинга страниц со словарями фразеологизмов и лингвистических терминов.
Чтобы воспользоваться кодом, необходимо необходимо запустить бота из файла *tgbot.py*. Для корректной работы необходимы все исполняемые файлы из этого репозитория (кроме *webparsers*), нужно также установить переменную среды TOKEN, который можно получить от BotFather в Telegram.
В файле *using_ai.md* описана наша работа с ИИ при написании кода проекта.
