# lingvoigry
**Участники:** Никитин Михаил, Кукшинова Дарья, Сушко Полина, Усенко Анастасия

Проект представляет собой телеграм-бота с четырьмя лингвистическими мини-играми. Бота можно добавлять в чаты или играть в одиночку.
Поддерживаемые игры: Лингвиселица (классическая виселица, в которой загадываются лингвистические термины и фразеологизмы; есть возможность выбрать для отгадывания одну из опций), ХОМО (игра, в которой участникам необходимо быстрее остальных придумать слово с заданным буквосочетанием), RuGramle (по спектрограмме нужно отгадать слово из 6 звуков за 6 попыток, отмечаются угаданные буквы), Угадай язык (по тексту надо понять, на каком языке он написан; есть возможность выбрать один из трех уровней сложности, система подсказок).

**Структура репозитория:** в main лежат все основные необходимые файлы (бот, транскрибатор текста, код, создающий спектрограммы, списки слов для Виселицы и ХОМО), в папке "угадай язык" содержатся все тексты (и картинки), необходимые для игры, "webparsers" содержит коды для парсинга страниц со словарями фразеологизмов и лингвистических терминов.
Чтобы воспользоваться кодом, необходимо необходимо запустить бота из файла tgbot.py. Для корректной работы необходимы все материалы из этого репозитория.
